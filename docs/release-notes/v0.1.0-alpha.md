# SAPIemu 0.1.0-alpha

První veřejná alfa verze emulátoru Tesla SAPI-1 pro Windows 10/11 (64 bit).

## Stažení a spuštění

1. Stáhněte `SAPIemu-0.1.0-alpha-win64.zip` a rozbalte ho kamkoli.
2. Spusťte `sapiemu.exe`. Windows u nepodepsaného programu ukáže SmartScreen: „Další informace“ → „Přesto spustit“.
3. Návod je v souboru `PRVNI-KROKY.md` v zipu. Nic se neinstaluje, nastavení a pracovní kopie disků zůstávají ve
   složce emulátoru.

## Co je uvnitř

- **Sestavy:**
  - ZPS-1 až ZPS-4 s MIKROBASICem, MIKOSem (V4, V5, MIKOS/D), CP/M 2.2/P a ELISem;
  - sestavy s MikroMonem a CP/M z RAM disku ZRMD-1 (ECMON);
  - sestava V z desek Libora Lasoty (JPR-1V, RAM-1V, AND-1V, DSM-1V, ZRD-1V, CGA-1V, MPH-1V).
- **Karty:**
  - procesorové: JPR-1, -1A, -1Z, -1ZI, -1V;
  - paměti: REM-1, RAM-1, -1A, -1Z, -1V, DMR-1;
  - RAM disky: RMD-1, ZRMD-1, ZRD-1V;
  - obraz: AND-1, -1A, -1Z, -1Z-89, -1V, DGD-1, DGD-1V, CGA-1V;
  - komunikace a disky: DSM-1 s magnetofonem, DSM-1V, RPD-1, IDE-1 s PMD32-SD;
  - zvuk: MPH-1V (YM3812, 82C54, joystick, myš).
- **Konfigurátor sestavy** s panely karet, propojkami a mapou portů a paměti.
- **Debugger**, ukládání stavu, nahrávání programů (Intel HEX, binární), zvuk (MPH-1V, bzučák), joystick
  a myš, sériové linky přes TCP a COM.
- **`sapiemu-cli`** pro běh bez okna a **MCP server** pro práci s Claude.

## Známá omezení

- Jen Windows. Linux se plánuje.
- Některé karty z katalogu se zatím neemulují: DPP-1, RTC-1, FDC-1, MFC-1A, DSP-1, DBS-1A, AND-30C, CRM-1,
  RAM-64, RPD-1Z. V konfigurátoru jsou označené.
- Řada detailů se teprve ověřuje na skutečném hardwaru, seznam je v `docs/SOUHRN.md` („Nejasnosti“).
- Soubory stavu (`.sapistate`) jsou vázané na verzi emulátoru.
- Hudba pro RAT PLAYER a SPLAY není součástí balíku, programy ano (`media/mph-1v`).
