# ZPS-1 with MIKROBASIC 2.4

The first SAPI-1 set (1983): an 8080 CPU, the AND-1 display (40 x 24 characters), the ANK-1 membrane keyboard and
a tape recorder. MIKROBASIC is in EPROM, you type a program right after power on.

## Try it

1. Click the screen window so that typing goes to the SAPI keyboard. The screen shows `MIKRO BASIC`, `READY` and
   the prompt `>`.
2. Type a short program (or use the button Type into SAPI):

```
10 FOR I=1 TO 5
20 PRINT I,I*I
30 NEXT I
RUN
```

3. It prints the numbers 1 to 5 and their squares. `LIST` shows the program, `NEW` clears it.

## More

- Programs are saved on a cassette in the tape recorder (Media window, New cassette..., RECORD), see
  [MIKROBASIC](../../docs/software/MIKROBASIC.md) (Czech).
