# ZPS-3 s CP/M 64K Tesla IMA

ZPS-3 přinesl disketovou jednotku 8" s řadičem RPD-1 a operační systém CP/M. Tady je původní CP/M 2.2 64K od
Tesly IMA. Na disketě v jednotce B: je MBASIC a COBOL.

## Vyzkoušejte

1. Klikněte do okna obrazovky. CP/M naběhne s výzvou `A>`.
2. `DIR B:` ukáže programy na druhé disketě.
3. Přepněte se na B: a spusťte MBASIC (načítání z diskety chvíli trvá):

```
B:
MBASIC
```

4. MBASIC napíše `31227 BYTES FREE` a `OK`. Zkuste `PRINT 6*7`, `SYSTEM` vrátí do CP/M.

## Dál

- Diskety se mění v okně Média. CP/M pro ZPS-3: [CP/M ZPS-3](docs/software/CPM_ZPS-3.md).
