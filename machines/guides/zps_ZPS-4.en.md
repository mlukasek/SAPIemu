# ZPS-4 with CP/M 62K

ZPS-4 has a Z80 CPU (the JPR-1Z card), the AND-1Z display with 64 x 20 characters, an 8" floppy and the RMD-1 RAM
disk. The system is CP/M 2.2/P 62K by R. Peřina, by the documentation of the time the basic version for ZPS-4.

## Try it

1. Click the screen window. `CPM V2.2 V/P1` starts with the prompt `A>`.
2. `DIR` lists the system disk (BIOS sources, `CPM.DOC`, programs W40, W64, X64...).
3. `TYPE CPM.DOC` shows the description of the system of the time (Czech).

## More

- The RMD-1 RAM disk is drive E:. After power on it holds random data like real DRAM, `RTEST` prepares it.
