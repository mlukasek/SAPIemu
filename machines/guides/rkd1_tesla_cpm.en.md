# Cartridge disk RKD-1 (CP/M Tesla Elstroj)

The CM 5403 cartridge disk with the RKD-1 controller: a removable cartridge and a fixed disk in one drive. The
system is the original CP/M 2.2 of Tesla Elstroj (1987) with a simple shell. The drive is drawn in the Media
window.

## Try it

1. After start enter a user number, e.g. `1`, and an area name. The prompt `b1$` means drive B:, user 1.
2. `DIR A:` lists the system cartridge (shell, formatter, sources of the system).
3. The fixed disk is new: `FORMTRKD`, keys `2` and `3` (C: and D:), Enter, `a`. F8 speeds up the formatting.
4. `PIP C:=E:STAT.COM` copies a program from the floppy to the fixed disk.
