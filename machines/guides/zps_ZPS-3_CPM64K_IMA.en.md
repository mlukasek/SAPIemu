# ZPS-3 with CP/M 64K of Tesla IMA

ZPS-3 brought the 8" floppy drive with the RPD-1 controller and the CP/M operating system. This is the original
CP/M 2.2 64K of Tesla IMA. The disk in drive B: has MBASIC and COBOL.

## Try it

1. Click the screen window. CP/M starts with the prompt `A>`.
2. `DIR B:` lists the programs on the second disk.
3. Switch to B: and start MBASIC (loading from the disk takes a while):

```
B:
MBASIC
```

4. MBASIC prints `31227 BYTES FREE` and `OK`. Try `PRINT 6*7`, `SYSTEM` goes back to CP/M.
