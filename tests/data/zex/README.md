# ZEXDOC / ZEXALL

Testy instrukční sady Z80 (Frank D. Cringle, úpravy J. G. Harston). Licence GPLv2 nebo novější, viz hlavička
`zexdoc.src`. Soubory pocházejí z https://github.com/floooh/chips-test (`tests/roms/`).

Spouští je `tests/test_zex.cpp` s minimálním CP/M BDOS (funkce 2 a 9), jen v optimalizovaném buildu (ctest label `slow`).
